SPIDER WEB · BACKUP

Personal encrypted Google Drive backup

SPIDER WEB Backup is a personal-use, self-hosted integration under development. It is designed to protect the SQLite records of a read-only cryptocurrency market observer, using restic encryption and Google Drive storage through rclone.

Purpose and Google Drive access

Only the OAuth scope https://www.googleapis.com/auth/drive.file is requested. The application is intended to manage only its own authorized backup files, not inspect unrelated Drive content. It checks the selected Drive account identity and available storage before permitted operations.

Backup safeguards

  • Backups are intended to be encrypted locally before upload.
  • OAuth credentials and encryption passwords belong in the owner's private environment, never on this website.
  • Backup execution requires separate operator approval.
  • Live cloud backups and independent recovery are not yet production-verified.
  • The service does not execute trades or offer public user accounts.
